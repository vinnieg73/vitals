How to read Vitals

Everything your Mac is doing, on one screen. Colour only shows up when something needs you.

Gray fine
Amber have a look
Red act now

Reading the map the big picture

swap
Bigger tile, more memory. Each app gets a tile sized by the RAM it holds.
The solid tile is the single biggest user. Start there.
Stripes are wired memory. It can't be freed.
The amber strip is swap: memory that spilled onto the SSD.

When memory is strained pressure amber or red

Look at the biggest tile. Right now it's the Claude sandbox VM at 10.1 GB, more than half your memory.
Quit what you aren't using. Select a row and press ⌘⌫. Each idle Claude Code session gives back 180–340 MB.
Restart the hungry app. Quitting and reopening Claude shrinks its VM back down for a while.
Still amber after an hour? Restart the Mac. It empties swap and stops the extra SSD writing.

What each number means in plain English

Memory pressurenow 78%

How hard the Mac is working to find room in memory. Low is fine. High means it is squeezing and swapping, and things slow down.

Swapnow 6.02 GB

When memory is full, the Mac parks some of it on the SSD. It works, but it's much slower than RAM and every write wears the SSD a little.

Compressednow 3.07 GB

Memory the Mac has squashed to fit more in. Cheaper than swap, but squashing and unsquashing costs some CPU.

Wirednow 2.71 GB

Memory macOS has locked for itself (mostly kernel_task). It can't be freed or swapped out.

Energy impacttop 38.2

A score for how much power an app is using right now. It has no unit; just compare apps with each other.

Load averagenow 5.2

How many tasks wanted the CPU, averaged over 1, 5 and 15 minutes. Below 11, your core count, the CPU is keeping up.
